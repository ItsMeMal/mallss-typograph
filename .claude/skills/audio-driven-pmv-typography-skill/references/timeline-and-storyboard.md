# Timeline and Storyboard Template

Build one authoritative edit timeline. All visual elements reference this same timeline.

| ID | Start–End | Audio cue | Exact text | Visual mode | Asset | Composition | Motion / transition |
|---|---|---|---|---|---|---|---|
| S01 | 00:00.00–00:03.20 | intro / quiet | [if any] | photo-led | img_01 | small title lower-left, broad negative space | slow push; cut on first vocal |
| S02 | 00:03.20–00:06.10 | first phrase | [exact phrase] | mixed | img_02 | image left, oversized type right | mask reveal; type exits through image edge |

Replace example content; never reuse it as a fixed formula.

## Minimum scene fields
- unique ID;
- start/end in seconds and frames;
- audio cue and confidence (measured / manually checked / estimated);
- exact text or “no text”;
- visual mode;
- asset path(s);
- focal point and layout;
- typography treatment;
- entrance / hold / exit;
- transition;
- QA note.

## Frame conversion
At frame rate `fps`, frame index is `round(time_seconds * fps)`. Use a consistent frame convention throughout the project. Avoid separately timing text, photos, and effects with independent approximate clocks.

## Timing priorities
1. Speech/vocal onset and phrase endings.
2. Major musical accents and section changes.
3. Visual readability and intentional holds.
4. Fine percussion details only where they add value.

Do not snap every event to a beat if the performance is intentionally ahead, behind, swung, rubato, or free-time.
