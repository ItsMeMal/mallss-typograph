# PMV Typography Quality-Control Checklist

## Audio and sync
- [ ] Video starts and ends as intended; no accidental black tail.
- [ ] Voice/lyrics appear at the correct moment.
- [ ] Major hits, drops, pauses, and transitions feel intentional.
- [ ] No drift between audio and visual timeline.
- [ ] Source audio is preserved and not clipped.

## Story and visual direction
- [ ] There is a recognizable concept and visual identity.
- [ ] Visual mode changes only when motivated by the sound/story.
- [ ] Photos/footage are relevant, correctly cropped, and visually cohesive.
- [ ] Typography-only passages have intentional composition, not generic subtitles.
- [ ] Mixed scenes integrate text and imagery instead of stacking unrelated layers.
- [ ] No repetitive slideshow or identical beat-synced effect loop.

## Typography
- [ ] All words, punctuation, names, and diacritics are correct.
- [ ] Font supports the language and characters used.
- [ ] Text is readable at actual viewing size.
- [ ] Line breaks, kerning, tracking, and margins are intentional.
- [ ] No accidental clipping, collisions, or overlaps.

## Motion
- [ ] Every movement supports rhythm, emotion, or meaning.
- [ ] Strong effects are reserved for strong moments.
- [ ] Holds and negative space are used where useful.
- [ ] No excessive shake, blur, glitch, or strobing.
- [ ] Transitions connect scenes through a clear visual idea.

## Technical
- [ ] Correct aspect ratio, dimensions, and frame rate.
- [ ] Correct duration and frame count.
- [ ] Audio stream is present and synchronized.
- [ ] No missing media, font fallback, render artifacts, or unintended black frames.
- [ ] Final video has been watched at normal speed with sound.
- [ ] Final export and editable project are saved in clearly named locations.
