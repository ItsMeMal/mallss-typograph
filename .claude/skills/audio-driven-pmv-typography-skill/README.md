# Audio-Driven PMV Typography Studio

A Claude Skill for creating full PMV typography / audio-driven motion-design videos.

## Supported visual approaches
- Typography-only
- Photo-led / image sequence
- Typography + photography / footage
- Abstract / graphic motion
- Footage-led
- Any intentional combination of the above

The skill does **not** force every project into the same style or assume every video is a text-only lyric video.

## Install in Claude
1. Open Claude's Skills / Customize page.
2. Choose **Create skill** or **Upload a skill**.
3. Upload `audio-driven-pmv-typography-skill.zip`.
4. Enable the skill.
5. In a Claude conversation, explicitly ask it to use `audio-driven-pmv-typography-skill` when planning or producing a video.
